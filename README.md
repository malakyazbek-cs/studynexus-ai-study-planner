# StudyNexus: AI-Powered Study Planner

An AI-powered, cross-platform study planner developed as a graduation project at the Islamic University of Lebanon, Department of Computer Science.

## About

StudyNexus helps students organize their studies, manage tasks, plan study sessions, and track their academic progress. It combines a Flutter mobile application with a PHP admin portal, using Firebase as a shared backend.

## What Makes StudyNexus Special?

- **AI-Powered Planning:** Generates personalized study schedules based on tasks, deadlines, exams, and available time.
- **Smart Insights:** Analyzes study activity to identify habits, progress, and areas for improvement.
- **AI Management:** Allows administrators to manage AI prompts, monitor generated results, and review activity logs.
- **Real-Time Synchronization:** Keeps data updated across the mobile app and admin portal.
- **Learning Analytics:** Tracks focus, productivity, consistency, and subject performance.
- **Student Engagement:** Includes study sessions, a Pomodoro timer, friends, messaging, streaks, and a weekly leaderboard.

## Technologies Used

- **Mobile App:** Flutter, Dart
- **Admin Portal:** PHP, HTML, CSS, JavaScript
- **Backend:** Firebase Authentication, Cloud Firestore, Realtime Database
- **AI Integration:** Google Gemini API
- **Security:** OAuth 2.0, JWT, CSRF protection

## Key Features

- User registration, login, and guest access
- Subject, task, and schedule management
- AI-generated study plans and personalized insights
- Study session tracking and Pomodoro timer
- Performance analytics and progress heatmaps
- Friends, real-time messaging, and leaderboards
- Notifications and PDF study plan export
- Admin dashboard for user management and AI monitoring

## What Users Can Do

**Students:** Organize subjects and tasks, generate study plans, track study sessions, review analytics, and connect with friends.

**Administrators:** Manage users, monitor activity, configure AI prompts, and review AI-generated schedules and insights.

## How the System Works

1. The Flutter application provides the student interface.
2. Firebase handles authentication, data storage, and real-time synchronization.
3. The Gemini API generates personalized study schedules and insights.
4. The PHP admin portal manages users and monitors system and AI activity.

## Future Improvements

- **AI-Based Task Completion Evaluation:** Use AI to estimate task completion percentages from students’ session summaries, task details, study duration, and previous progress. Provide explanations of completed work and remaining tasks to improve tracking accuracy and personalize recommendations.

- **Collaborative AI Study Groups:** Introduce group study sessions with shared Pomodoro timers, progress tracking, group statistics, motivational AI messages, and achievement badges. Add optional, consent-based screenshots to support accountability while respecting students’ privacy.

These improvements could make StudyNexus more intelligent, accurate, collaborative, and motivating, creating a more personalized learning experience for students.
